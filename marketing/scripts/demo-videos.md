# TRADIFY — Demo video pack (4 videos)

Each video is an 8s AI-generated 9:16 (1080×1920) clip in `attached_assets/generated_videos/`.
Recommended use: TikTok / IG Reels / YT Shorts / Meta Stories. Crop center 1:1 for feed; letterbox to 16:9 for YouTube pre-roll.

The clips are deliberately **text-free** so you can:
1. Add captions/text overlays per platform (TikTok native auto-captions, IG sticker text, etc.)
2. Stitch multiple clips into a 30s ad (suggested cuts below)
3. Voiceover-ready — scripts below
