Library: Nodemailer
Purpose: Transactional emails only
Cost: $0 beyond Workspace subscription
Scalability: Temporary (planned migration later)

1️⃣ Sender & Inboxes (Decide Once)

Use clear role-based emails:

no-reply@tradifyapp.com
 → all system emails

support@tradifyapp.com
 → contact form + replies

billing@tradifyapp.com
 → optional later

⚠️ Do not send system emails from a personal inbox.

2️⃣ Google Workspace Setup (One-Time)
Required steps:

Enable 2-Step Verification

Create App Password for:

App: Mail

Device: Other (Tradify App)

Save the 16-character password securely

DNS (Must be correct):

SPF: include Google

DKIM: enabled in Admin Console

DMARC: at least p=none initially

This ensures deliverability.

3️⃣ Backend Structure (Clean & Future-Proof)

Create a single service:

/services/emailService.ts


Responsibilities:

Nodemailer transport config

One function per email type

Central error handling

Easy provider swap later

👉 When you migrate, you replace only this file.

Store as HTML files (best early-stage choice):

/emails/
  welcome.html
  verify-email.html
  reset-password.html
  subscription-activated.html
  subscription-canceled.html


Use placeholders:

{{user_name}}
{{action_url}}
{{plan_name}}
{{support_email}}


No inline AI generation. No JSX emails.

5️⃣ Events → Emails Mapping (Tradify)
Authentication

Signup → Verify email

Verify success → Welcome email

Password reset request → Reset email

Password reset success → Confirmation email

Subscription (via PayPal webhooks)

System

Contact form → Support inbox + auto-reply

Admin-created user → Set password email

You must:

Limit password reset attempts

Log email sends (success/fail)

Retry once on failure

Never expose SMTP credentials

This prevents abuse and account flags.
